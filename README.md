# Harley Tutors v2

Premium Next.js + Tailwind website for Harley Tutors.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy on Vercel

1. Upload these files to the GitHub repository connected to your Vercel project.
2. Commit to the `main` branch.
3. Vercel will detect Next.js and deploy automatically.

The current WhatsApp number is set in `app/page.tsx`.
